# Traduction (français / anglais)

Le jeu est bilingue. Le **français du code est la clé** : `t('Ouvrir un booster')` rend la phrase telle quelle en français et sa
traduction en anglais. Une phrase sans traduction s'affiche en français (jamais de clé technique) et se retrouve avec
`node src/i18n/i18n.check.cjs` ou, en jeu, dans `window.__i18nMissing`.

## Fonctionnement

- `src/i18n/index.ts` : `t(clé, {param})`, `tp(singulier, pluriel, n, {param})`, `locale`, `setLocale`, `dateLocale`.
- La langue est **fixée au chargement** : changer de langue (Réglages › Paramètres) enregistre `garageverse:lang` puis recharge. Les
  constantes de module peuvent donc être traduites (`const label = t('…')`). Sans choix, un joueur qui a déjà une partie reste en
  français ; un nouveau joueur suit la langue du navigateur.
- Dictionnaire anglais : `src/i18n/en/*.ts`, un fichier par zone (`Record<phrase française, traduction>`). Une même phrase dans deux
  fichiers doit avoir la même traduction.

## Règles d'écriture

1. **Une clé est une chaîne littérale** : `t('Défi réussi')`. Jamais de gabarit construit (`` t(`Défi ${n}`) ``) : écrire
   `t('Défi {n}', { n })` et, dans l'anglais, `'Challenge {n}'`. Les `{paramètres}` doivent être identiques des deux côtés.
2. **Pluriels** : `tp('{n} voiture', '{n} voitures', n)` ; les deux phrases ont chacune leur entrée anglaise (`'{n} car'`, `'{n} cars'`).
   Le français met 0 et 1 au singulier, l'anglais seulement 1.
3. **Traduire à l'affichage, jamais les données** : les valeurs qui servent à la logique, aux filtres, aux tris ou à la sauvegarde
   (`Légendaire`, `Courante`, tags, catégories, identifiants, clés de `localStorage`) restent françaises. On écrit `{{ t(v.rarity) }}`.
   Un texte venu d'un JSON ou d'une constante (`v.story`, `part.text`, `rival.bio`) se traduit de la même façon : la phrase française
   est la clé de l'entrée anglaise.
4. **Attributs** : `aria-label="Réglages"` devient `:aria-label="t('Réglages')"` ; idem `title`, `placeholder`, `alt`.
5. **Rien à traduire** : noms de voitures, de marques et de personnages, noms de produits (Neon Drive, Synthwave, GarageVerse), symboles
   (₡, ⟶, ◆), nombres, classes CSS, identifiants, commentaires (restent en français, comme le reste du code).
6. Un texte dynamique composé de morceaux (`'Il te manque ' + n + ' crédits'`) devient **une phrase entière** avec paramètres : l'ordre
   des mots n'est pas le même en anglais.
7. Un module qui n'importe pas encore `t` : `import { t } from '../i18n'` (chemin relatif adapté).

## Style de l'anglais

- Anglais américain, ton direct et amical. Le « tu » du jeu devient « you » ; pas de formules lourdes.
- Libellés de boutons courts, à l'impératif (« Open a booster », « Race »). Même mot français → même mot anglais dans tout le jeu
  (Garage, Booster, Stage, Série → Set, Spéciale → Special, Palier → Tier, crédits → credits, Nitro, Overdrive, Versus).
- Conserver les majuscules, les guillemets « » → “ ”, et les espaces avant `:` `?` `!` disparaissent en anglais.
- Garder l'humour et les jeux de mots quand c'est possible ; sinon un équivalent naturel plutôt qu'un mot à mot.

## Ajouter un texte

1. Écrire `t('Phrase en français')` dans le code.
2. Ajouter `'Phrase en français': 'English sentence',` dans le fichier de zone de `src/i18n/en/`.
3. `node src/i18n/i18n.check.cjs`, puis `node node_modules/.bin/vue-tsc --noEmit`.

Les notes de version existent dans les deux langues : `CHANGELOG.md` et `CHANGELOG.en.md` (mêmes versions, mêmes dates).
